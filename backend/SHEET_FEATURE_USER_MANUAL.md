# Natural-Language Spreadsheet Querying & Manipulation User Manual

This manual details the architecture, configuration, endpoints, natural-language query capabilities, and mutation safeguards for spreadsheet products and services in the Echo backend.

---

## 1. Overview & Architecture

The natural-language spreadsheet feature allows users and frontend interfaces to upload, view, query, and manipulate structured tabular business data (Products and Services) using natural language.

The system is organized into four decoupled services:
1. **`sheetSchemaService.js`**: Canonical schema definitions for products and services. Validates all requested columns, value types, and operators. Strictly prevents access to unknown tables or fields.
2. **`sheetQueryPromptBuilder.js`**: Transforms user natural-language queries into structured JSON using Google AI Studio (Gemini). Understands semantic variations (e.g., "out of stock" vs "zero units"), asks for clarification when requests are ambiguous, and explains schema limitations rather than inventing columns.
3. **`sheetQueryService.js`**: Accepts validated JSON queries and executes safe parameterized SQL against PostgreSQL. The database is never queried with raw SQL generated by the language model.
4. **`sheetMutationService.js`**: Implements safe, two-phase data modifications (preview and confirmed execution) inside database transactions. Requires explicit confirmation (`confirm: true`) before modifying or deleting records.

## 2. Environment Configuration

Ensure the following variables are configured in `backend/.env`:

```env
# Server Configuration
PORT=3000
HOST=localhost
NODE_ENV=development

# PostgreSQL Database Connection
DATABASE_URL=postgresql://user:password@host:port/database?sslmode=require
DB_SSL=true
DB_SSL_REJECT_UNAUTHORIZED=false

# Google AI Studio (Gemini API) Configuration
GEMINI_API_KEY=your-gemini-api-key
GEMINI_MODEL=gemini-3.5-flash-lite
```

To run the database migrations:
```bash
npm run db:init
```

## 3. Supported Schemas

### Products Table (`products`)
| Column | Type | Nullable | Description | Allowed Query Operators |
| :--- | :--- | :--- | :--- | :--- |
| `id` | UUID | No | Primary Key | `equals` |
| `business_id`| UUID | No | Scoped Business ID | System-managed |
| `name` | String | No | Product name | `equals`, `contains`, `starts_with`, `ends_with`, `in` |
| `description`| Text | Yes | Details & specifications | `contains`, `not_contains`, `equals` |
| `price` | Numeric(10,2) | No | Unit price in USD (>= 0) | `equals`, `greater_than`, `less_than`, `between` |
| `stock` | Integer | No | Available inventory count (>= 0) | `equals`, `greater_than`, `less_than`, `between` |
| `category` | String | Yes | Category (e.g. Outerwear, Bags) | `equals`, `contains`, `in` |
| `size` | String | Yes | Size (e.g. S, M, L, XL, 42) | `equals`, `in` |
| `color` | String | Yes | Color (e.g. Red, Black, Blue) | `equals`, `contains`, `in` |
| `created_at` | Timestamptz | No | Record creation timestamp | `equals`, `greater_than`, `relative_days_ago`, `this_month` |

### Services Table (`services`)
| Column | Type | Nullable | Description | Allowed Query Operators |
| :--- | :--- | :--- | :--- | :--- |
| `id` | UUID | No | Primary Key | `equals` |
| `business_id`| UUID | No | Scoped Business ID | System-managed |
| `name` | String | No | Service name | `equals`, `contains`, `starts_with`, `ends_with` |
| `description`| Text | Yes | Scope of work details | `contains`, `not_contains`, `equals` |
| `rate` | Numeric(10,2) | No | Hourly/flat rate in USD (>= 0) | `equals`, `greater_than`, `less_than`, `between` |
| `availability`| String | No | `'available'` or `'unavailable'` | `equals`, `not_equals` |
| `size` | String | Yes | Project scope size (Small, Medium, Large) | `equals`, `in` |
| `available_from`| Date | Yes | Earliest scheduling date | `equals`, `greater_than`, `less_than`, `after`, `before` |
| `created_at` | Timestamptz | No | Record creation timestamp | `equals`, `greater_than`, `relative_days_ago`, `this_month` |

## 4. Endpoints Reference

### 4.1 Two Separate CSV Upload Endpoints

#### 1. Upload Products CSV
- **URL**: `POST /api/sheets/products/upload` (or `POST /api/businesses/:businessId/sheets/products/upload`)
- **Query Parameter (Optional)**: `?businessId=684a8863-5094-4c8b-9b15-c50c06335b7f`
- **Body**: `multipart/form-data` with field key `file` (or `customer_csv`)
- **Required CSV Columns**: `name,price,stock` (optional: `description,category,size,color,created_at`)
- **Re-upload Behavior**: Discards any pre-existing products for the business and replaces them with the new copy in a single database transaction.

**Success Response (`200 OK`)**:
```json
{
  "message": "Products CSV imported successfully.",
  "business_id": "684a8863-5094-4c8b-9b15-c50c06335b7f",
  "entity": "products",
  "source_file": "sample-products.csv",
  "total_rows": 16,
  "imported_count": 16,
  "rejected_count": 0,
  "errors": []
}
```

#### 2. Upload Services CSV
- **URL**: `POST /api/sheets/services/upload` (or `POST /api/businesses/:businessId/sheets/services/upload`)
- **Query Parameter (Optional)**: `?businessId=684a8863-5094-4c8b-9b15-c50c06335b7f`
- **Body**: `multipart/form-data` with field key `file` (or `customer_csv`)
- **Required CSV Columns**: `name,rate,availability` (optional: `description,size,available_from,created_at`)
- **Re-upload Behavior**: Discards pre-existing services for the business and replaces them with the new copy.

**Success Response (`200 OK`)**:
```json
{
  "message": "Services CSV imported successfully.",
  "business_id": "684a8863-5094-4c8b-9b15-c50c06335b7f",
  "entity": "services",
  "source_file": "sample-services.csv",
  "total_rows": 12,
  "imported_count": 12,
  "rejected_count": 0,
  "errors": []
}
```

### 4.3 Natural-Language Query Endpoint

- **URL**: `POST /api/sheets/query` (or `POST /api/businesses/:businessId/sheets/query`)
- **Headers**: `Content-Type: application/json`

#### Example 1: Products Out of Stock
**Request**:
```json
{
  "entity": "products",
  "message": "List products that are out of stock."
}
```
**Response**:
```json
{
  "status": "ok",
  "interpretedQuery": {
    "entity": "products",
    "operation": "filter",
    "filters": [
      {
        "field": "stock",
        "operator": "equals",
        "value": 0
      }
    ],
    "sort": [],
    "limit": null
  },
  "rows": [
    {
      "id": "928de771-4cc2-4210-a780-2fae343fc4f2",
      "name": "Trail Rain Jacket",
      "price": "129.99",
      "stock": 0,
      "size": "XL",
      "color": "Red"
    }
  ],
  "count": 4,
  "business_id": "684a8863-5094-4c8b-9b15-c50c06335b7f"
}
```

#### Example 2: Combined Filter (Red in Size XL)
**Request**:
```json
{
  "entity": "products",
  "message": "Find red products in size XL."
}
```
**Interpreted Filters**:
- `color = 'Red'`
- `size = 'XL'`

#### Example 3: Text Matching in Description
**Request**:
```json
{
  "entity": "products",
  "message": "Find products matching this description: waterproof and lightweight."
}
```
**Interpreted Filters**:
- `description contains 'waterproof'`
- `description contains 'lightweight'`

#### Example 4: Clarification Needed (Missing Date)
**Request**:
```json
{
  "entity": "services",
  "message": "Find services available after a specified date."
}
```
**Response**:
```json
{
  "status": "clarification_needed",
  "message": "Which date should I use to check service availability?",
  "entity": "services",
  "rows": [],
  "count": 0,
  "business_id": "684a8863-5094-4c8b-9b15-c50c06335b7f"
}
```

#### Example 5: Schema Limitation (Non-Existent Column)
**Request**:
```json
{
  "entity": "products",
  "message": "Show products where weight is over 5kg."
}
```
**Response**:
```json
{
  "status": "clarification_needed",
  "message": "Schema limitation: Field \"weight\" does not exist on entity \"products\". Available fields: name, description, price, stock, category, size, color, created_at.",
  "entity": "products",
  "rows": [],
  "count": 0
}
```

### 4.4 Mutation Endpoint (Preview & Confirmation Safeguards)

- **URL**: `POST /api/sheets/mutate` (or `POST /api/sheets/mutation`)
- **Headers**: `Content-Type: application/json`

#### Step 1: Preview Mutation (`confirm: false`)
**Request**:
```json
{
  "entity": "products",
  "message": "Change the price of Trail Rain Jacket to 150.",
  "confirm": false
}
```
**Response (`200 OK`)**:
```json
{
  "status": "preview",
  "operation": "update",
  "entity": "products",
  "confirmation_required": true,
  "message": "Found 2 record(s) matching criteria. Submit with \"confirm\": true to apply proposed changes.",
  "affected_count": 2,
  "target_rows": [ ... ],
  "proposed_changes": {
    "price": 150
  },
  "diff": [
    {
      "id": "5debb461-d4cd-4665-820a-fc34658e4bea",
      "name": "Trail Rain Jacket",
      "changes": {
        "price": {
          "current": "129.99",
          "proposed": 150
        }
      }
    }
  ],
  "business_id": "684a8863-5094-4c8b-9b15-c50c06335b7f"
}
```

#### Step 2: Confirmed Execution (`confirm: true`)
**Request**:
```json
{
  "entity": "products",
  "message": "Change the price of Trail Rain Jacket to 150.",
  "confirm": true
}
```
**Response (`200 OK`)**:
```json
{
  "status": "success",
  "operation": "update",
  "entity": "products",
  "affected_count": 2,
  "updated_rows": [
    {
      "id": "5debb461-d4cd-4665-820a-fc34658e4bea",
      "name": "Trail Rain Jacket",
      "price": "150.00",
      "stock": 14,
      "updated_at": "2026-10-27T06:24:48.614Z"
    }
  ],
  "message": "Successfully updated 2 products record(s).",
  "business_id": "684a8863-5094-4c8b-9b15-c50c06335b7f"
}
```

```bash
npm test --prefix backend
```

Test coverage includes:
- Products and services CSV parsing and validation.
- Row-level error collection for malformed rows.
- Complete table listings (`GET`).
- All 11 natural-language query scenarios for Products and Services.

- Clarification responses for ambiguous dates or non-existent columns.
